# 客户需提供清单

> 用途：列出摩兽需要准备的账号、资料和人员，分"节前三件事"和"开工前"两组，逐项写明用途、格式与截止时间。读者：Kim 及摩兽相关同事（非技术读者）。
> 标记说明：【待核实】＝平台要求仍在向官方核实；【待客户确认】＝需要摩兽提供或拍板；【张宝文确认】＝由张宝文最终确定。
> 假设：正式开工日按 2026-10-12 计【张宝文确认】；"建议负责人"一栏为建议，请摩兽填入实际姓名【待客户确认】。

## 怎么用这份清单

1. 先做第一组"节前三件事"，它们决定项目能不能按期开工。
2. 第二组在开工日前备齐即可，可以边碰面边确认。
3. 每项后面的"状态"请自行填写：未开始、进行中、已完成。有疑问联系张宝文。

### 1. 启动 Meta 商家认证（2026-09-30 前提交）

为什么急：商家认证（Business Verification，Meta 对企业真实身份的核验）和之后的显示名审核，时间由 Meta 决定，是整个项目里最不可控的一环：Meta 官方说法是商家认证审核最长 14 个工作日，材料被退回重交还要再等一轮。Meta 的审核不受国庆假期影响，材料在节前交上去，假期就不会白白浪费。

怎么做：

1. 确定用哪个公司主体做认证【待客户确认】。该主体的法定名称要与 Meta 商务账户里填写的名称、官网上的公司信息一致。
2. 指定一名 Meta 商务账户管理员。如果摩兽已经有投广告用的商务账户，沿用同一个即可【待客户确认】。
3. 备齐下表材料，在 Meta 商务管理平台的商家认证功能中提交【待核实】。
4. 把提交日期和审核状态告诉张宝文。

| 材料 | 要求 |
|---|---|
| 营业执照 | 法定名称、地址与商务账户中填写的完全一致；扫描件清晰、在有效期内 |
| 地址或电话证明 | 近期的水电或电话账单、银行对账单等，抬头与公司名称一致 |
| 公司官网 | 域名与公司或品牌对应；页面上能看到公司名称和联系方式 |
| 公司域名邮箱 | 用于接收验证邮件 |
| 验证联系人 | 能接听验证电话或接收验证邮件的人 |

具体材料以 Meta 后台的提示为准【待核实】。

常见被退回的原因：名称与执照不一致；文件模糊或过期；官网上找不到公司信息；地址、电话与提交的文件对不上。

### 2. 整理 100 至 200 条历史咨询（2026-10-09 前）

用途：上线前用这些真实咨询评测 AI 判得准不准，并据此调整规则。没有真实数据，就无法验证分类质量，验收也无从谈起。

要求：

1. **保留客户原话**，不要改写、不要翻译。
2. 覆盖面要广：B 端和 C 端都要有，其中 B 端不少于 30 条；各主要语种都要有；垃圾消息、无关咨询也要保留一些，AI 同样要学会识别。
3. 来源不限：各平台私信、WhatsApp、邮件都可以。
4. 请销售对每条给出判断，这就是评测用的"正确答案"。

格式（Excel 或 CSV，我方另发标注模板）：

| 列 | 说明 | 示例 |
|---|---|---|
| 编号 | 顺序号 | 001 |
| 日期 | 咨询日期 | 2026-08-15 |
| 渠道 | 咨询从哪来 | Instagram 私信 |
| 客户号码 | 至少保留国家码 | +49 开头 |
| 客户原话 | 同一客户的多条消息可合并 | （原文） |
| 销售判断 | 有效 B 端、无效 B 端、C 端、无关，四选一 | 有效 B 端 |
| 提到的车型 | 没有就留空 | MC10 |
| 备注 | 后续有没有成交等 | |

脱敏：可以删去客户姓名、邮箱、详细地址，但请保留号码国家码和原话。
