## 4. 主要假设与风险（影响人天的）

1. 客户历史咨询 100–200 条在开工日前到位，且销售参与标注；否则离线评测人天上浮 1–2。
2. 路线 A 成立（内置 AI Agent 抽取稳定）。走路线 B 时，集成模块 +1 人天（外部调用与 Code Action 联调），仍在完整版区间内；精简版需与张宝文重新确认。
3. 通知渠道只接 1 种（飞书或企业微信二选一）。两种都要 +0.5 人天。
4. 线索存储默认 SQLite + CSV 导出；要同步飞书多维表格或 Google Sheets 时 +1 人天。
5. 知识库内容由客户提供素材，我方只做结构化与导入；代写 FAQ 不含在内。
6. 需求变更按人天另计，口径见 `pricing-internal.md`。
