# ADR 0006：模型选型

> 用途：记录"用哪个大模型"的评估框架与候选；不预设任何一家，由评测数据与客户主体的可开通性决定。读者：集成工程师、张宝文。
> 状态：评估框架已采纳（2026-09-21）；选型结论待开工第 1 周离线评测后填写。

## 背景

- 无论走路线 A 还是 B（`0003-ai-route-a-b.md`），离线评测与生产必须用同一模型、同一版 prompt。
- 咨询以英语为主，另有西、德、法、葡等语种（具体语种【待客户确认】），小语种上的分类质量是主要不确定项。
- 客户主体在中国大陆，另有欧洲服务中心（SOURCES 第 4 节）；由哪个主体签约、付款，决定了哪些模型开得出来【待客户确认】。
- 官方条款限制：不得让 WhatsApp 业务数据被用于训练或改进任何 AI 模型，仅限为自己专用而微调的除外（SOURCES S-M5）。

## 候选

| 候选 | 说明 |
|---|---|
| 1. Botmaker 内置模型 | 路线 A 的自然选择。未指定时默认为帮助中心所写的 "GPT-4 Mini"，可按 Bot 或按 AI Agent 切换；可选清单未公开。帮助中心 "Botmaker 3.0 - AI Agents" 栏目另写 3.0 版默认模型为 "Open AI 5.4"、目前不能换；两种说法很可能分属两代界面，新账号落在哪一代、能否指定模型【待核实】（SOURCES S-B8）。按 token 经 Botmaker 计费，单价未公开（SOURCES S-B7）。数据条款：官网写明 Co-pilot（坐席回复建议）用坐席与客户的对话训练 ChatGPT 模型，上线不启用；AI Agent 的对话是否用于训练未写，公开页面没有 DPA（SOURCES S-B17） |
| 2. 国际 OpenAI 兼容接口 | 路线 B 时由境外 VPS 上的集成服务调用；接口形式通用，评测工具已支持 |
| 3. 客户主体可合规开通的模型 | 客户现有云厂商或境内可签约、可开票的模型服务，多数提供 OpenAI 兼容接口；评测工具同样支持 |

评测工具同时带 OpenAI 兼容与 Anthropic 两种客户端（`04-eval/`），候选范围不受工具限制。

## 评估维度与现状

| 维度 | 1. Botmaker 内置 | 2. 国际 OpenAI 兼容接口 | 3. 客户主体可合规开通的模型 |
|---|---|---|---|
| 主体可开通性 | 高：随 Botmaker 账号开通，无需另签 | 取决于签约主体：境内主体直接签约与付款可能受限，境外主体可行性更高【待客户确认】 | 高：人民币结算、可开票 |
| 多语言质量 | 待评测：试用账号 20 条加离线评测集 | 待评测 | 待评测；德、法、西、意、葡等小语种是主要不确定项 |
| 成本 | 单价未公开【待核实】；成本模型按每百万 token 1.0 至 5.0 USD 的占位区间估算 | 公开价位低；路线 B 的模型费在任何档位都很小（`03-whatsapp/cost-model-results.md`） | 低 |
| 数据条款 | 服务条款写 Botmaker 对客户数据的使用限于提供服务，但隐私政策另有"改进服务、研究"用途；Co-pilot 原文写明用于训练 ChatGPT 模型（不启用）；AI Agent 的对话与下游模型供应商（至少两家）是否用于训练、有无 DPA 与子处理方清单，公开页面都没有，须书面问 Botmaker【待核实】（SOURCES S-B17） | 需选择有"不用于训练"承诺的商用接口档位，并留存书面依据【待核实】 | 同上；另需评估欧盟用户数据进入境内模型服务的跨境合规【待客户确认】需法务复核 |
| 运维 | 无 | 多一个密钥与账单 | 多一个密钥与账单 |

"待评测"的格子不预填结论。

## 决策方法

1. 客户历史咨询标注完成后，用同一评测集、同一版 prompt 跑各候选（路线 A 的候选用与 Botmaker 所选相同的模型在线下跑；前提是试用账号能确认实际模型名称、线下能调到同一模型，见 SOURCES S-B8 与 `02-botmaker/trial-test-plan.md` 的 T-12）。
2. 先过门槛，再比成本：
   - 门槛：`06-acceptance/thresholds.json` 的全部离线阈值；其中 B 端召回率是主指标，分语种结果单独看，不允许某个已选语种明显掉队。
   - 门槛之上：比每 100 条成本（评测报告自动给出）与主体可开通性。
3. 数据条款是一票否决项：拿不到"不用于训练"的书面依据的候选直接排除。
4. 发给模型的内容只含对话文本，不含手机号等标识信息。
5. 结论连同评测报告一起记到本文件末尾；之后换模型视同换 prompt 版本，要重跑评测。

## 影响

- 路线 A 成立且内置模型过门槛：不引入第二个模型供应商，最省事。
- 走路线 B 或内置模型不过门槛：需要客户主体开通一个模型账号，开通时间计入 W1。
- 无论选哪个候选，Botmaker 的 Co-pilot 都不启用（SOURCES S-B17、S-M5）。
- Botmaker 内置模型若因数据条款被一票否决，退到路线 B 也不够：路线 B 下对话与 FAQ 仍由内置 AI Agent 承担（`0003-ai-route-a-b.md` 决策第 2 条），届时 Botmaker 内的 AI 怎么用要重新决策【张宝文确认】。
- 小语种不过门槛时的退路：该语种的自由文本一律按 `low_confidence` 转人工，按钮分流照常工作；语种范围随报价档位收缩。
