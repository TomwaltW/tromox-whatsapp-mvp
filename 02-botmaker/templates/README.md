# 再触达模板：总览与提交审核注意事项

> 用途：24 小时客服窗口关闭后，销售或售后只能用经 Meta 预审的模板消息重新联系客户；本目录是这些模板的源文件与提交须知。读者：集成工程师（提交审核）、客户运营与销售（知道什么时候用哪一条）。
> 假设：三条模板都按 utility（事务通知）类别提交；Meta 可能把它们改判为 marketing（营销）类，费率与发送条件随之变化【待核实】；ES / DE / FR / PT 译文为占位，语种清单与译文均【待客户确认】，须由母语者审核后再提交。

## 1. 模板清单

| 模板名 | 用在什么时候 | 谁发 | 档位 |
|---|---|---|---|
| `tromox_sales_followup_v1` | B 端线索的窗口已关，销售要继续跟进 | 销售 | 精简版、完整版 |
| `tromox_info_request_v1` | B 端资料没收齐，窗口已关，需要客户补充信息 | 销售或运营 | 精简版、完整版 |
| `tromox_support_update_v1` | 售后请求有进展，窗口已关 | 售后或运营 | 仅完整版 |

精简版提交前两条、覆盖 2 个语种；完整版三条全上、覆盖全部已选语种（与报价单的档位范围一致）。

## 2. 什么时候必须用模板

1. 客户最后一条消息之后 **24 小时内**，可以自由回复，不需要模板。
2. 超过 24 小时，只能发已通过审核的模板；客户一旦回复，窗口重新打开 24 小时，之后又可以自由回复。
3. 所以模板的唯一目的就是**请客户回一句话**。三条模板的结尾都是"请回复本消息"，并带快捷回复按钮。
4. 响应时限规则见 `00-client/销售接手SOP.md`：工作时间内 2 小时首次回复；非工作时间进线的，下一个工作日 10:00（北京时间）前回复；周末无人值班时，周一用模板再触达。时限数值均【待客户确认】。
5. 2026-10-01 起，窗口内发送的 utility 模板同样按条计费（SOURCES S-M1），与自由回复同价，所以窗口内没有理由用模板。

## 3. 提交审核前逐项检查

| # | 检查项 | 说明 |
|---|---|---|
| 1 | 类别选 utility | 内容必须围绕客户自己发起的那次咨询，不含促销、优惠、新品推荐、节日问候；出现这些内容会被改判为 marketing【待核实】 |
| 2 | 模板名 | 只用小写字母、数字、下划线；带版本后缀 `_v1`。已通过的模板不原地改，改动一律新建 `_v2` |
| 3 | 每个语种单独提交 | 同名模板下按语种各建一份；语言代码（如西语、葡语的地区变体）按目标市场选【待客户确认】 |
| 4 | 变量 | 用 `{{1}}`、`{{2}}`、`{{3}}` 顺序编号；正文不能以变量开头或结尾；每个变量都要填示例值，示例值要像真的（人名、日期、单号），不要填 "test" |
| 5 | 变量不要太多 | 正文里固定文字要明显多于变量，否则容易被拒【待核实】 |
| 6 | 不含联系方式跳转 | 不放个人 WhatsApp、个人电话、短链接；后续沟通就在本会话、公司号上进行 |
| 7 | 按钮 | 只用快捷回复按钮，标题不超过 25 个字符【待核实】；第二个按钮给客户一个体面的"不需要了"，减少被拉黑与举报 |
| 8 | 页眉页脚 | 不用页眉；页脚可放品牌名，不放营销语 |
| 9 | 语气 | 与 Bot 一致：礼貌、简洁、无表情符号、无感叹号堆叠 |
| 10 | 发送对象 | 只发给主动联系过我们的人，且只针对那次咨询；不导入外部名单，不群发 |

提交入口：在 Botmaker 后台的 WhatsApp 模板管理功能中【待核实】；也可用 API `POST /whatsapp/templates`（限 1 次/秒，SOURCES S-B2）。审核通常较快，但 W2 第一天就提交，不要等到 UAT（`07-project/timeline.md`）。

## 4. 常见被拒或被改判的原因

| 原因 | 怎么避免 |
|---|---|
| 含促销或引导购买的措辞 | 只说"跟进您的咨询""请回复以继续" |
| 变量位置或示例值不合规 | 见上表第 4 项 |
| 与已有模板内容重复 | 每条模板用途单一，不要换个名字重复提交 |
| 语种与内容不符 | 译文由母语者审核；不要在西语模板里夹英文句子 |
| 内容过于笼统，看不出事务性质 | 写清是哪一天、哪一类请求的后续 |

## 5. 上线后的质量监控

1. 模板有质量评级；被大量拉黑或举报会被暂停，并拖累号码的质量评级（`03-whatsapp/meta-onboarding-checklist.md` 第 7 节）。
2. 同一客户同一咨询，模板最多发 2 次，间隔不少于 3 天；两次都没回就把线索状态记为 `nurture` 或 `closed_lost`，不再追发【待客户确认】。
3. 客户点了"不需要了"之类的按钮或回复拒绝，立即停止再触达，并在线索备注里记录。
4. 每月看一次模板的送达、已读与回复情况：在 Botmaker 后台的模板或通知报表功能中【待核实】。
5. 模板费用按收件人国家码计价，并加 Botmaker 20% 服务费（SOURCES S-B3）；测算见 `03-whatsapp/cost-model.md`。

## 6. 文件约定

每个模板一个文件，结构固定：基本信息、英文主稿、各语种占位、变量表与示例值、按钮、使用说明、版本记录。译文审核通过后，把占位替换成正式译文并在版本记录里登记。
